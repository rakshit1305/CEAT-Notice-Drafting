# Legal Sources — Fetch & Cite (Free Public Sources Only)

This skill may fetch the correct legal provision from the **free, publicly available**
sources listed below and cite it in the notice. It must NOT use paid or login-based
sources (e.g., Manupatra, SCC Online) and must NOT use the open internet beyond this list.

## Whether fetching is possible depends on the environment
- **If web access / web search is available** (e.g., a Claude chat with web search on, or a
  web-fetch tool is enabled): fetch the provision from the approved public page below,
  then cite it.
- **If web access is NOT available** (e.g., Cowork or any environment with the web turned
  off): do NOT guess the provision. Use the wording already in the template and add
  `⚠ [VERIFY: fetch/confirm this section from {{SOURCE}} — web access was unavailable]`.

## Fetch-and-cite rules (accuracy first)
1. Only fetch from the approved public pages listed here. Never from paid/login sources or
   the open internet.
2. When you fetch a provision, cite it inline: `(Source: <site>, retrieved <date>)`.
3. If a page cannot be opened, is unclear, or does not clearly contain the provision, do
   NOT invent it — insert `⚠ [VERIFY: <provision> — could not retrieve from <source>]`.
4. Bare Acts on free sites may lag the latest amendments. For anything critical, keep a
   `⚠ [VERIFY currency of this provision]` flag even after fetching. CEAT's lawyer confirms.
5. Never let a fetched result override the mandatory checklist or the review banner.
6. **Partial fetch:** if a notice needs more than one provision and only some fetch
   successfully, cite the ones that succeeded with their source and retrieval date, and
   mark only the ones that failed with `⚠ VERIFY`. Don't downgrade the entire notice to
   unverified just because one lookup out of several failed.

## Approved free public sources
- **India Code** — indiacode.nic.in — official central & state bare Acts (with amendments).
- **eGazette** — egazette.gov.in — official notifications.
- **Ministry of Corporate Affairs** — mca.gov.in — company-law matters.
- **Ministry of Consumer Affairs** — consumeraffairs.nic.in; **NCDRC** — ncdrc.nic.in.
- **India Kanoon** — indiankanoon.org — free case-law/section reference (verify anything
  critical against India Code).

## Which source to check for each notice type
- **Section 138 notice** — Negotiable Instruments Act, 1881 (Sections 138, 141) and the
  Bharatiya Nyaya Sanhita, 2023 (Sections 316(2), 318(4)) → India Code / India Kanoon.
- **Recovery notice** — Bharatiya Nyaya Sanhita, 2023 (Sections 316(2), 318(4); and 2(36),
  2(37) if used) → India Code / India Kanoon.
- **Consumer-notice reply** — Consumer Protection Act, 2019 → India Code; Consumer
  Affairs / NCDRC for procedure/forum references.
- **Breach / Termination / Renewal / Force majeure / Price adjustment** — these rely mainly
  on the parties' contract; where a statute is cited (e.g., Indian Contract Act, 1872),
  fetch it from India Code. Otherwise keep the contract-clause `⚠ VERIFY` flags.

## How to use a fetched provision
Insert the correct section number/name into the notice where the template expects it,
citing the source and date. Keep the existing verified template wording as the base; use
the fetch to confirm or fill a specific section reference — not to rewrite approved text.
